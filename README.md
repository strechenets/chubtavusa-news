# Новини додатку «Чуб та Вуса»

Файл `news.json` і фото з `images/` читає мобільний додаток барбершопу «Чуб та Вуса» під час запуску.

- `items` — новини, найновіші першими.
- `date` — `РРРР-ММ` або `РРРР-ММ-ДД`.
- `image` — шлях до фото відносно цього файлу (JPEG, ширина до 1080 px, без метаданих).
- `tag`, `title`, `short`, `text`, `alt` — тексти українською (`uk`), російською (`ru`) і англійською (`en`).
