# Новини додатку «Чуб та Вуса»

Файл `news.json` і фото з `images/` читає мобільний додаток барбершопу «Чуб та Вуса» під час запуску. Сторінка: https://strechenets.github.io/chubtavusa-news/news.json (GitHub Pages, кеш до 10 хв).

## Правила файлу (інакше додаток тихо пропустить запис або весь файл)
- `version` — версія схеми, **завжди `1`**. Не змінювати: додаток з іншою версією файл не прийме.
- `updated` — дата правки `РРРР-ММ-ДД`.
- `items` — новини, найновіші першими, **не більше 20**. Порожній список `[]` означає «новин немає».
- `id` — унікальний рядок до 80 знаків (латиниця, цифри, `-`).
- `date` — `РРРР-ММ` або `РРРР-ММ-ДД`.
- `image` — лише відносний шлях усередині цього сховища, напр. `images/beard.jpg` (латиниця, цифри, `-`, `_`; `.jpg`, `.png` або `.webp`). Без `https://`, `/` на початку, `..`, `?`, `#`.
- `tag`, `title`, `short`, `text`, `alt` — об'єкти `{uk, ru, en}`; **`uk` обов'язковий**, якщо `ru` чи `en` немає, додаток покаже `uk`.
- Довжина: `tag` до 40 знаків, `title` до 140, `short` і `alt` до 200, `text` до 1200.
- Фото: JPEG, ширина до 1080 px, без метаданих (EXIF і геоданих), до ~200 КБ.
- Розмір усього `news.json` — до 200 КБ.

Перед публікацією перевір, що файл — правильний JSON.
